# General Torsion Explorer

## Setup Your Environment:
linux/wsl:
```shell
python3 -m venv venv
. ./venv/bin/activate
pip install -r requirements.txt
```

windows:
```shell
python3 -m venv venv
./venv/bin/activate.ps1
pip install -r requirements.txt
```

## Run examples
```shell
python3 ./examples.py
```
